# @parta5/importer

Импорт курсов из Moodle `.mbz`-бэкапов в Парту5: разбор манифеста, секций,
активностей (`page`, `label`, `resource`, `url`, `quiz`) и банка вопросов
(Moodle `questions.xml` / Moodle XML / GIFT), с загрузкой файлов в S3-совместимое
хранилище.

## CLI

```bash
pnpm --filter @parta5/importer import:run -- \
  --file /path/to/backup.mbz \
  --school demo \
  --user teacher@demo.ru \
  [--dry-run] [--keep-temp]
```

- `--file` — путь к `.mbz` (tar.gz или zip, определяется автоматически).
- `--school` — slug школы (`School.slug`), в которую импортируется курс.
- `--user` — email пользователя (`User.email`), который станет автором курса;
  должен принадлежать указанной школе.
- `--dry-run` — только разбор и отчёт, ничего не пишется в БД и хранилище.
- `--keep-temp` — не удалять временную директорию с распакованным бэкапом
  после завершения (для отладки).

Скрипт читает `DATABASE_URL` и `S3_*` переменные окружения из процесса —
загрузки `.env` внутри CLI нет. Запускать из корня репозитория с
подгруженным окружением, например:

```bash
env $(grep -v '^#' .env | xargs) pnpm --filter @parta5/importer import:run -- \
  --file backup.mbz --school demo --user teacher@demo.ru --dry-run
```

В режиме `--dry-run` хранилище не используется вовсе (передаётся заглушка,
которая бросает исключение при любом обращении) — импортировать без записи
в S3 гарантированно безопасно.

### Пример отчёта (dry-run)

```
DRY-RUN: изменения НЕ применены

Курс: Физика 9 класс (fizika-9-klass-ab12cd)
Модулей: 5, уроков: 23, блоков: 31
Файлов: 4 (2.7 МБ)
Квизов: 2, вопросов: 18
Пропущено вопросов по типам: essay=3, matching=1

Пропущенные активности:
- [forum] Обсуждение темы — Неизвестный тип активности: forum

Предупреждения:
- вопрос Q7 essay пропущен: тип не поддерживается в MVP
```

## Ограничения MVP

- Типы вопросов: `multichoice`, `truefalse`, `shortanswer`. Остальные (`essay`,
  `matching`, `numerical`, …) пропускаются с фиксацией в отчёте
  (`questions.skippedByType`).
- Активности `forum`, `assign`, `scorm` и другие, кроме `page`/`label`/
  `resource`/`url`/`quiz`, пропускаются целиком (`skippedActivities`).
- Файлы, встроенные в HTML вопросов (картинки в тексте вопроса/ответа), не
  переносятся — сами вопросы импортируются, но встроенные ссылки на файлы
  останутся битыми.
