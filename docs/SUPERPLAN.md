# Парта5 — СУПЕРПЛАН развития (2026-07)

> Роадмап верхнего уровня, пересобранный по итогам ревью (`docs/reviews/2026-07-senior-product-review.md`).
> Цель ближайших месяцев: **пилот с реальным контентом Профспецресурса** (106 курсов, 62,9 тыс. multichoice-вопросов, 773 PDF).
> Исполнение — конвейером младших моделей (Claude Code CLI / Sonnet) по PROMPTS.md; каждый этап разбивается на самодостаточные промпты с критериями приёмки.

## Принципы

1. **Сначала безопасность, потом фичи.** Этап A закрывает дыры (RBAC, RLS), на которые квиз-движок иначе ляжет сверху и умножит их.
2. **Скоуп от реального контента.** Квиз-движок MVP = multichoice + truefalse + shortanswer (покрывает 99,997% PSR). Остальные типы вопросов — после пилота.
3. **Импортер — продуктовая фича, не разовый скрипт.** Парсим стандартный `.mbz`, а не БД PSR напрямую: тот же код потом продаёт миграцию любой организации с Moodle.
4. **Каждый этап заканчивается работающим e2e-сценарием** и зелёным CI.
