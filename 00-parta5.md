## Текущий статус

**🟢 Phase 0 — закрыт** (2026-05-26). Все 10 шагов выполнены, 14 коммитов. Платформа умеет: signup школы, логин, CRUD курсов/модулей/уроков/блоков, прохождение учеником с прогрессом, self-host через Docker Compose. CI на GitHub Actions работает.

**🟢 Phase 1 — закрыт** (2026-05-26). Платформа умеет полноценный блочный редактор с 12 типами блоков, self-hosted видео через FFmpeg+HLS, прогресс по блокам, DRAFT/PUBLISHED/ARCHIVED publishing flow. Демо-курс «Введение в бег» в сиде. E2E тесты на Playwright.

**🔵 Следующее — Phase 2** (см. `phase-2.md`): тесты и задания (банк вопросов, quiz engine, ручная и авто-оценка).

## Ключевые решения

| Решение            | Что выбрано                        | Почему                                                                                                                                                    |
| ------------------ | ---------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Бренд              | **Парта5**                         | 5 как высшая оценка в РФ, школьная семантика, домен доступен                                                                                              |
| Домен              | **parta5.ru**                      | Стандартная цена, `parta.ru` стоил 490к                                                                                                                   |
| Лицензия           | **MPL 2.0**                        | Не AGPL (отпугнёт интеграторов), не Apache (даст конкуренту закрыть форк)                                                                                 |
| Бизнес-модель      | **open-core**                      | Бесплатное ядро для школ + платный SaaS-облако + платные модули                                                                                           |
| Стек               | **Next.js 15 + Prisma + Postgres** | Сильные стороны Paul, быстрая итерация, AI-фичи нативно                                                                                                   |
| Мульти-тенантность | **с первого коммита**              | Переписывать потом в 10 раз дороже                                                                                                                        |
| Видео              | **Self-hosted HLS + embed**        | FFmpeg-воркер в ядре, никаких внешних SaaS обязательно. Embed YouTube/RuTube/VK/Kinescope/Vimeo как опция. Соответствует self-host философии «как Moodle» |
| Аутентификация     | **Auth.js + ЕСИА OIDC**            | Стандарт для школьного сегмента в РФ                                                                                                                      |

## Конкурентный ландшафт

| Кто            | Тип                   | Доминирует в               |
| -------------- | --------------------- | -------------------------- |
| Moodle         | Open-source self-host | Школах РФ (по факту)       |
| Skillspace     | Закрытый SaaS         | Корпоративном обучении     |
| iSpring Learn  | Закрытый SaaS         | Корпоративном обучении     |
| Teachbase      | Закрытый SaaS         | Корпоративном обучении     |
| МТС Линк Курсы | Закрытый SaaS         | Корпоративном обучении     |
| **Парта5**     | **Open-core**         | **Школах и УДО РФ** (цель) |

Школьная ниша слабо занята современными решениями — Moodle устарел, конкуренты закрытые и не подходят бюджету школ.
